# What is WaaP?

**Wallet as a Protocol (WaaP)** represents the next evolution in Web3 wallet technology, combining a cutting-edge interface with uncompromising security. We've created the smoothest and most secure way to leverage our revolutionary **[Human Keys](https://human.tech/blog/human-keys)** technology—a breakthrough that's reshaping how humans interact with the digital world.

## Uncompromising Security Architecture

**WaaP** eliminates single points of failure through advanced **Two-Party Computation (2PC)** technology, ensuring no single user, company, or code section can compromise your assets.

### Dual-Share Security Model

Your private key is split into two mathematically-linked shares:

- **Sovereign Share** - Generated via the Human Network from your personal inputs, ensuring you maintain control
- **Security Share** - Managed in a Trusted Execution Environment (TEE), invisible to you but essential for security

### Advanced Protection Features

- **Blind Signing Resistance** - Transaction simulation prevents malicious signatures
- **Malware Protection** - 2PC architecture resists device compromise
- **Policy-Based Security** - Configurable spending limits and authorization rules
- **Zero Trust Model** - Every transaction verified through multiple security layers

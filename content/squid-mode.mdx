# Squid Mode

Squid Mode is WaaP's decentralized signing mode. Instead of a single co-signing enclave, a threshold network of independent validators — built on [Ika](https://ika.xyz)'s 2PC-MPC protocol — co-signs every transaction.

Same social login. No seed phrase. The self-custody guarantee is now cryptographic, not contractual.

## How it works

WaaP already splits your private key into two shares using [two-party computation (2PC)](/security). Neither share can sign alone. Squid Mode builds on top of this:

| | Standard | Squid Mode |
|---|---|---|
| Your share | On your device | On your device |
| Co-signer | WaaP's secure enclave | Ika's threshold network |
| Policy engine | Yes | Yes |
| Seed phrase | None | None |

Under Squid Mode, the co-signer side is distributed across Ika's independent validators instead of a single enclave. The request that asks the network to sign cannot be constructed without policy approval — if the policy doesn't agree, the network won't sign.

Your key never exists in one place. Even the network cannot sign without you.

## What chains does Squid Mode support?

One WaaP login provisions signing across multiple chains from a single account:

- **EVM** — Ethereum, Optimism, Polygon, Arbitrum, Base, Gnosis, Avalanche, Celo, Fantom, zkSync, Linea, Scroll, Aurora, HyperEVM
- **Sui** — Native signing via ed25519
- **Solana** — Native signing via ed25519, which Sui and Solana both read natively, so the same account signs on both

Squid Mode uses two key curves under the hood: `secp256k1` for EVM chains, and `ed25519` for Sui and Solana. You don't need to manage this — one account handles all three.

## How do I enable Squid Mode?

Squid Mode is available in the WaaP web app. When creating a new account, you'll see an account selector with two options:

- **Standard account** — Protected by WaaP
- **Squid account** — Protected by WaaP + Ika MPC

To get started:

1. Go to [waap.xyz](https://waap.xyz)
2. When creating a new account, select **Squid account** in the account selector
3. Your wallet is provisioned with decentralized co-signing from the start

Squid Mode is a choice you make when setting up your account. Your existing standard account continues to work as before.

## What about policies and 2FA?

Everything carries forward. Squid Mode inherits the same protections as a standard WaaP account:

- **Spend limits** — Daily limits you control
- **Transaction scanning** — Every transaction is checked before signing
- **2FA** — High-risk transactions can require your approval via Telegram, email, phone, or hardware wallet
- **Privileges** — Scoped, time-limited access tokens work the same way

The policy engine runs in the same place it always did — between you and the co-signer. In addition to WaaP's policy gate, which is unchanged, a Squid account adds Ika's threshold network as the co-signer.

## Squid Mode for agents

For developers running AI agents with WaaP wallets, Squid Mode adds a decentralized co-signer without changing how the agent operates.

The agent authenticates via API key and operates within the policy engine. The agent holds no raw private keys in its runtime. Hijack it completely and you've captured a session token — every ask still has to clear the policy. Under a standard account, WaaP's enclave co-signs. Under Squid Mode, Ika's threshold network co-signs. Same containment, different trust model.

Squid Mode is available in the WaaP CLI, the WaaP SDK and waap.xyz from launch.

## Current limitations

- **New accounts only** — Squid Mode is selected at account creation. You cannot convert an existing standard account to Squid Mode.

## FAQ

### Do I need to migrate my existing account?

No. Standard accounts continue to work. Squid Mode is available when creating a new account.

### Is Squid Mode more secure?

Both modes enforce the same policy boundary and key-splitting guarantee. The difference is the trust model: under Squid Mode, the co-signer is a distributed network of independent validators instead of a single enclave. Neither mode gives any single party access to your full key.

### Does Squid Mode cost more?

Squid Mode pricing hasn't been published yet. Ask us in the chat bubble or on [Discord](https://discord.gg/humantech) and we'll get you the current answer.

### Can I switch between modes?

Squid Mode is selected at account creation. Switching between modes is not currently supported.
